# Challenge Alura

## *Análise de Desempenho das Lojas – Data Science Project*

O presente projeto foi desenvolvido durante minha formação em **Ciência de Dados pelo programa Oracle Next Education (ONE)**, com o objetivo de analisar o desempenho de quatro lojas e identificar qual delas apresenta os piores resultados, recomendando a venda com base em indicadores técnicos.

A análise foi realizada utilizando **Python**, com foco em boas práticas de manipulação, exploração e visualização de dados.

---

## *Objetivo do Projeto*
O caso proposto consistia em responder à pergunta:

**“Qual loja da sua rede Alura Store vender para iniciar um novo empreendimento?”**

Foram avaliados:

- Faturamento total por loja  
- Produtos mais e menos vendidos por loja 
- Categorias mais e menos vendida por loja
- Média de avaliação dos clientes por loja
- Custo médio de frete pro loja
